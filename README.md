# 🎬 CineSQL Insights – IMDB Dataset SQL Analysis

## 📌 Project Overview

An end-to-end Data Analytics project focused on analyzing the IMDB movie dataset using SQL, Python, SQLite, pandas, and matplotlib. This project demonstrates database creation, SQL querying, data analysis, and visualization techniques for extracting meaningful insights from movie data.

---

## 🚀 Features

✔️ SQLite database creation
✔️ SQL query analysis
✔️ Data cleaning using pandas
✔️ Movie trend analysis
✔️ Ratings & genre insights
✔️ Data visualization with matplotlib

---

## 🛠️ Technologies Used

* Python
* SQLite
* pandas
* matplotlib
* Jupyter Notebook

---

## 📊 Insights Generated

📌 Top-rated movies
📌 Most popular genres
📌 Year-wise movie trends
📌 Rating distribution analysis
📌 Highest voted movies

## 🎯 Project Goal

To practice SQL querying, data analysis, and visualization techniques on real-world movie datasets while building a portfolio-ready analytics project.
